# Крушители подземелий: Бездна

Карточный рогалик в браузере и на Android (React + Vite + Tailwind + Capacitor).

- Три акта, карта с развилками, колода, реликвии, зелья, события, лавка, костры.
- Фирменная механика **«Слом»**: у врагов есть Гард и стихия-слабость; сломай Гард, и враг оглушён.
- Мета-прогресс: души и Святилище, уровни сложности, ежедневный забег.

Код: `src/game` — правила (чистый редьюсер `engine.ts`, данные в `data/`), `src/ui` — интерфейс.
Баланс: числа врагов в `data/enemies.ts`, карт в `data/cards.ts`, множитель Гарда `GUARD_MULT` в `engine.ts`.

    npm install
    npm run dev
    npm run build
