# Сборка Android-приложения (APK)

Игра остаётся обычным веб-проектом (React + Vite). Чтобы получить `.apk`, мы заворачиваем
готовую веб-сборку в оболочку **Capacitor** — это маленькое Android-приложение с встроенным
браузером (WebView), которое открывает вашу игру. Всё работает без интернета.

Есть два способа. Начните со **Способа А**: он не требует ничего устанавливать.

---

## Обновление с нового устройства (быстро)

```bash
git clone https://github.com/<ваш-логин>/<репозиторий>.git
cd <репозиторий>
# распакуйте архив ПОВЕРХ папки с заменой (папку .git не трогайте)
# package-lock.json из архива не входит — оставьте свой
npm install
git add .
git commit -m "Update: оптимизация + Путь перерождений"
git push
```
Затем GitHub → **Actions** → **Build Android APK** → **Run workflow**.
Ставьте новый APK **поверх** старого (не удаляя): тогда сохранение в приложении сохранится.

## Графика и производительность
В игре: вкладка **Ещё** → кнопка **Графика**: Авто / Высокая / Экономная.
«Авто» сама переключается на экономный режим, если FPS стабильно низкий.

## Таланты, питомцы, «кукла» героя
- **Таланты** (вкладка «Герой»): 4 таланта на каждый класс, до 5 уровней. 1 очко за каждые 2 уровня героя, после перерождения очки возвращаются.
- **Питомцы** (вкладка «Ещё»): с боссов падают яйца (30%), через 60 побед вылупляется питомец или растёт уже имеющийся (до 10 ур.). Помогает один выбранный питомец, он виден рядом с героем в бою. Питомцы не сбрасываются перерождением.
- **Кукла героя** (вкладка «Сумка»): надетые вещи вокруг персонажа, заточка прямо на плитке вещи.

## Классы, стихии, крафт
- **Классы** (Воин, Маг, Вор): выбираются при первом запуске и после каждого перерождения, хранятся в сохранении (localStorage). Класс показан рядом с именем героя.
- **Стихии** врагов: 🔥 > ❄️ > 🌿 > 🔥. Стихию атаки героя выбирают кнопки под способностями (или «Авто»). Верная стихия: +50% урона, неверная: -25%.
- **Крафт** (вкладка «Крафт»): 2 обычные вещи одного слота → 1 необычная, 2 необычные → 1 редкая.

## Заточка, гоблин, ежедневная награда
- **Заточка:** вкладка «Сумка», кнопка под надетой вещью. До +10, каждый уровень даёт +10% к атаке, защите и HP вещи за золото. Заточка остаётся на вещи и повышает цену продажи.
- **Гоблин-казначей** 👺 (шанс 4% с 2-го этажа): мало HP, но золота в 10 раз больше.
- **Ежедневная награда:** вкладка «Ещё». Серия дней подряд увеличивает награду (до 7 дней), каждый 7-й день даёт ещё и души.

## Задания и реликвии
Вкладка **Ещё**. Три постоянных задания (убить монстров, боссов, элиту, крит-удары, способности,
дойти до этажа) дают золото и иногда души; после выполнения появляется новое, сложнее.
Реликвии (8 видов) падают с боссов, усиливаются дублями до 10 уровня и не сбрасываются перерождением.

## Путь перерождений
Новые постоянные награды за число перерождений (1, 2, 3, 4, 5, 6, 7, 8, 10, 12, 15):
больше уровней навыков, скидка в лавке, навык «Неистовство», способность «Берсерк»,
больше места в сумке, лучшие сундуки, больше душ, сохранение золота при смерти.
Полный список — в игре, вкладка **Ещё**.

## 0. Что нужно сделать в любом случае

1. Распакуйте архив **поверх** своей папки с игрой (с заменой файлов).
   `node_modules` и `.git` в архив не входят — ваша история Git останется нетронутой.
2. В папке проекта выполните один раз:
   ```bash
   npm install
   ```
   Это поставит новые пакеты (Capacitor) и **обновит `package-lock.json`**.
   Нужен **Node.js 22 или новее** (`node -v`). Если версия старее — поставьте LTS с nodejs.org.
3. Отправьте всё на GitHub:
   ```bash
   git add .
   git commit -m "Dungeon Crasher 2.0 + Android"
   git push
   ```
   Страница на GitHub Pages обновится сама, как и раньше.

> Почему в workflow стоит `npm install`, а не `npm ci`: `npm ci` требует, чтобы `package-lock.json`
> точно совпадал с `package.json`. Пока вы не сделали шаг 2 и не закоммитили обновлённый lock-файл,
> `npm ci` на GitHub упал бы. После коммита lock-файла можно вернуть `npm ci` — по желанию.

## Способ А. APK собирает GitHub (без Android Studio)

1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Слева выберите **Build Android APK** → кнопка **Run workflow** → **Run workflow**.
3. Через 5–10 минут запуск станет зелёным. Откройте его и внизу, в разделе **Artifacts**,
   скачайте **dungeon-crasher-apk** (это zip, внутри `app-debug.apk`).
4. Перенесите `app-debug.apk` на телефон и установите (см. раздел «Установка на телефон»).

Сборка также стартует сама, когда вы публикуете тег вида `v1.0.1`:
```bash
git tag v1.0.1 && git push --tags
```

Что делает workflow (`.github/workflows/android.yml`): ставит Node 22 и Java 21, собирает игру,
создаёт папку `android/` (если её ещё нет в репозитории), генерирует иконку и заставку из
`assets/`, копирует игру в Android-проект и запускает Gradle (`assembleDebug`).

## Способ Б. Через Android Studio (у вас она есть)

### Что должно быть установлено
- **Android Studio Otter (2025.2.1) или новее.** Capacitor 8 старее не поддерживает.
  Обновить: *Help → Check for Updates*.
- **JDK 21.** Отдельно ставить не нужно: он идёт внутри Android Studio.
  Проверьте: *Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK* —
  выберите встроенный (JetBrains Runtime 21). Если видите ошибку `invalid source release: 21`,
  причина именно здесь.
- **Node.js 22+** (для `npm`).
- Android SDK Platform 36 — Android Studio предложит скачать сама при первой синхронизации.

### Шаги (один раз)
```bash
npm install            # если ещё не делали
npm run build          # собирает игру в папку dist/
npm run android:add    # создаёт папку android/ и ставит портретную ориентацию
npm run android:assets # иконка и заставка из папки assets/
npm run android:sync   # копирует свежую сборку игры в android/
npm run android:open   # открывает проект в Android Studio
```

Дождитесь, пока внизу Android Studio закончится *Gradle sync* (первый раз — несколько минут).

### Запуск на телефоне
1. На телефоне: *Настройки → О телефоне* → 7 раз нажмите «Номер сборки» → включится режим
   разработчика. Затем *Для разработчиков → Отладка по USB*.
2. Подключите телефон кабелем, разрешите отладку.
3. В Android Studio выберите свой телефон в верхней панели и нажмите зелёный ▶ **Run**.

### Получить файл APK
- **Быстро (debug):** *Build → Build Bundle(s) / APK(s) → Build APK(s)*. Файл появится в
  `android/app/build/outputs/apk/debug/app-debug.apk` (Studio покажет ссылку «locate»).
- **Из терминала:** `npm run android:apk`.
- **Подписанный release** (для друзей/магазина): *Build → Generate Signed Bundle / APK* →
  APK → создайте ключ (*Create new…*) → выберите вариант `release`.
  **Сохраните файл ключа и пароли** — без них обновить приложение потом не получится.
  Файлы `*.keystore` и `*.jks` уже добавлены в `.gitignore`: в репозиторий их класть нельзя.

### Когда вы поменяли что-то в игре
```bash
npm run android:sync   # пересобрать игру и скопировать в Android-проект
```
Затем снова ▶ Run или Build APK. Папку `android/` заново создавать не надо.

## Установка APK на телефон
1. Скопируйте `app-debug.apk` на телефон (кабель, Telegram «Избранное», облако).
2. Откройте файл. Android спросит разрешение «Установка из неизвестных источников» для
   приложения, из которого вы открыли файл (Файлы, Chrome и т. д.) — разрешите.
3. Нажмите «Установить». Debug-APK подписан отладочным ключом — это нормально для личного
   использования. Play Protect может показать предупреждение: «Всё равно установить».

## Важные особенности

**Сохранения не переносятся между версиями.** Прогресс в браузере (GitHub Pages) и в приложении
хранится отдельно — это два разных хранилища. В APK вы начнёте с нуля. Старое сохранение
старой версии игры *в браузере* подхватывается новой версией автоматически.

**Название, идентификатор, версия.**
- Название приложения — `capacitor.config.json`, поле `appName`.
- Идентификатор `appId` (`com.dungeoncrasher.game`) поменяйте **до** `npm run android:add`:
  после создания папки `android/` его менять неудобно. Для Google Play он должен быть уникальным.
- Версия — поле `version` в `package.json` (скрипт `patch-android.mjs` переносит её в Android).
  Для обновлений в Google Play увеличивайте ещё и `versionCode` в `android/app/build.gradle`.

**Иконка и заставка** лежат в `assets/` (рыцарь из игры). Замените PNG тем же размером и снова
выполните `npm run android:assets`.

**Звук** синтезируется прямо в игре, аудиофайлов нет, поэтому APK получается лёгким (порядка
нескольких мегабайт). Первое касание на заставке «Нажми, чтобы войти» включает звук.

**Ориентация** — только портрет (задаёт `scripts/patch-android.mjs`).

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `invalid source release: 21` | Gradle JDK → встроенный JDK 21 (см. выше). |
| Studio ругается на версию AGP/Gradle | Обновите Android Studio до Otter (2025.2.1) или новее. |
| Белый/чёрный экран в приложении | Забыли `npm run android:sync` после изменений игры. |
| `cap: command not found` | Запускайте через `npm run …` или `npx cap …` из папки проекта. |
| `android/ already exists` при `android:add` | Папка уже создана — просто делайте `npm run android:sync`. |
| Шаг «Generate icons» в GitHub красный | Не критично: APK всё равно соберётся со стандартной иконкой; посмотрите лог шага. |
| Статус-бар/вырез закрывает верх игры | Игра берёт отступы из `--safe-area-inset-*` (даёт Capacitor); проверьте, что нет старой версии `index.html` без `viewport-fit=cover`. |
| Телефон не виден в Studio | Включите отладку по USB, смените кабель, подтвердите окно на экране телефона. |

## Что где лежит

```
src/                      исходный код игры
  game/reducer.ts           все правила игры
  game/audio.ts             звуки (синтез, без файлов)
  gameData.ts               баланс, монстры, предметы, навыки, достижения
  components/               экраны и сцена боя (BattleScene, ParticleLayer, HeroSprite…)
assets/                   иконка и заставка для Android
scripts/patch-android.mjs доводка Android-проекта (портрет, версия)
capacitor.config.json     настройки Capacitor (appId, название)
.github/workflows/
  deploy.yml                веб-версия на GitHub Pages
  android.yml               сборка APK
```
